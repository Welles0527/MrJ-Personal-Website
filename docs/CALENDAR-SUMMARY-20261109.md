# Super Calendar colors and life summary

The summary uses the existing Life Calendar anniversary list and existing authenticated Personal Plan bridge. Anniversary dates retain their original icons and use the reference pink (#ff80c8) in both views. Unstarred personal tasks with snooker or football titles join starred tasks in the summary; other unstarred tasks stay excluded. Personal sports have colored icons; annual summaries show icons only, monthly summaries show icons and text. Tournament snooker icons inherit text color. Annual holidays remain separate pale-green dates with circled rest markers; football competition icons are blue.

The shared theme menu includes the previous warm appearance as 暖杏奶油, used by Travel Calendar. Home defaults to 奶油红粉 and Health defaults to 清新绿白. The corrected 超级日历 name appears in navigation, overview and accessible labels. Event color fills stay confined to monthly summaries; annual backgrounds mark holidays and anniversaries.

Validation: authenticated production-account reads through the existing local Life Calendar bridge, with both 1440x900 and 390x844 views. All actual snooker/football task dates were checked against the Life Calendar source and both summary views; all existing anniversary labels/icons and pink backgrounds were checked. No account data was changed. Local preview serves public sources plus framework-built pages/assets, including the previously missing Personal Plan source. JavaScript syntax, diff checks, Todo modal regression, full build and the bundled Bible regressions passed. Existing unrelated build warnings were observed; those pages are outside this release.

Release scope: only super-calendar/calendar-holidays.js, super-calendar/home-summary.js, super-calendar/index.html and generated release.json. The three live pre-release hashes match prior successful-release manifests. Changed static source files total 195,511 bytes before the release marker.
