如果把“献祭”理解为动物祭、素祭、奠祭、初熟之物以及相关礼仪，摩西五经中有很多章节。它们并不是重复或矛盾，而是分别规定了：

> **献什么、为什么献、谁来献、在哪里献、什么时候献、献多少。**

其中，**利未记16章**和**民数记29章**属于不同层面的规定：

* **利未记16章**：讲赎罪日当天，大祭司怎样进入至圣所，为圣所、祭司和全民赎罪。
* **民数记29章**：讲七月各节期公共献祭的日期、种类和数量。
* 民数记29:11特别说明，赎罪日所列的公山羊，是在“赎罪祭”和“常献的燔祭”之外另外献的，因此两章应当叠加理解。

# 一、最核心的献祭章节

| 章节               | 主要内容                    | 与民数记29章、利未记16章的差异                 |
| ---------------- | ----------------------- | --------------------------------- |
| **出埃及记12章**      | 逾越节羊羔                   | 家庭性、纪念出埃及、羊羔要吃掉，不是一般燔祭            |
| **出埃及记29章**      | 祭司承接圣职；每日早晚常献燔祭         | 规定祭司怎样被分别为圣，以及每天固定献什么             |
| **利未记1—7章**      | 五大祭的基本条例                | 献祭制度的总说明书，规定各种祭的目的和操作方法           |
| **利未记8—10章**     | 亚伦和儿子承接圣职；首次献祭；拿答、亚比户事件 | 主要是祭司就职和实际执行范例，不是节期数量表            |
| **利未记12、14、15章** | 产妇、麻风洁净者、漏症者洁净后的献祭      | 主要处理礼仪上的不洁，不代表生育或患病本身是犯罪          |
| **利未记16章**       | 赎罪日核心礼仪                 | 大祭司一年一次进入至圣所；两只公山羊中一只被杀、一只送到旷野    |
| **利未记17章**       | 宰杀地点、血不可食、生命在血中         | 不是列数量，而是规定祭牲在哪里宰杀、血怎样处理           |
| **利未记21—22章**    | 祭司资格、祭牲不可有残疾            | 规定“谁可以献”和“什么样的祭牲才蒙悦纳”             |
| **利未记23章**       | 全年节期日历                  | 强调节期日期、安息、聚会和属灵意义；数量多由民数记28—29章补充 |
| **民数记15章**       | 素祭、奠祭配比；误犯罪的献祭          | 规定一只羊、公绵羊、公牛分别配多少细面、油和酒           |
| **民数记28章**       | 每日、安息日、月朔、逾越节、七七节献祭     | 上半年和常规公共献祭时间表                     |
| **民数记29章**       | 吹角日、赎罪日、住棚节献祭           | 七月节期公共献祭的时间表和数量表                  |
| **申命记12、16章**    | 献祭地点和三大节期               | 强调必须在神所选择的地方献祭，以及全民一同守节           |

# 二、利未记1—7章：五种基本祭

这是理解其他献祭章节的基础。

## 1. 燔祭

**经文：利未记1章**

祭牲包括：

* 公牛；
* 绵羊或山羊；
* 斑鸠或雏鸽。

主要特点是祭牲几乎全部烧在坛上，表达：

* 赎罪；
* 敬拜；
* 完全献给神。

民数记28—29章所列大量公牛、公绵羊和羊羔，大部分都是燔祭。

---

## 2. 素祭

**经文：利未记2章**

不是动物，而是：

* 细面；
* 油；
* 乳香；
* 烤饼或煎饼；
* 初熟之物。

一部分烧在坛上，其余归祭司。素祭通常表达奉献、感恩，也经常与燔祭一同献上。

民数记29章多次说：

> “同献的素祭和奠祭，要照例照数献上。”

具体“照数”主要参照民数记15章。

---

## 3. 平安祭

**经文：利未记3章、7:11—36**

平安祭包括：

* 感谢祭；
* 还愿祭；
* 甘心祭。

它与燔祭最大的区别是，祭牲不是全部烧掉：

* 脂油归神；
* 一部分归祭司；
* 一部分由献祭者和家人享用。

所以平安祭具有与神相交、感恩和共同用餐的意义。

---

## 4. 赎罪祭，也可理解为洁净祭

**经文：利未记4章—5:13**

根据献祭者身份不同，祭牲也不同：

* 受膏的祭司：公牛；
* 全会众：公牛；
* 官长：公山羊；
* 普通人：母山羊或母绵羊；
* 贫穷人：鸟；
* 极贫穷者：细面。

它主要处理：

* 误犯的罪；
* 人或圣所受到的不洁污染；
* 需要恢复人与神关系的情况。

因此，中文译作“赎罪祭”容易让人以为每次都是因为道德犯罪。实际上，利未记12、14、15章中的赎罪祭，很多是为礼仪洁净而献。

---

## 5. 赎愆祭

**经文：利未记5:14—6:7**

赎愆祭主要针对：

* 误用圣物；
* 欺骗别人；
* 侵占财物；
* 不诚实起誓；
* 给别人造成实际损失。

除献公绵羊外，通常还必须：

> 归还原物，并另加五分之一。

因此它与赎罪祭的主要差别是：赎愆祭特别强调**赔偿和修复损害**。

---

# 三、出埃及记29章：祭司就职与每日常献祭

出埃及记29章有两部分。

## 1. 祭司承接圣职

亚伦和儿子承接圣职时要献：

* 一只公牛作赎罪祭；
* 一只公绵羊作燔祭；
* 一只公绵羊作承接圣职之祭；
* 无酵饼、油饼和薄饼。

血要抹在祭司的：

* 右耳垂；
* 右手大拇指；
* 右脚大拇指。

象征祭司的听从、服侍和行动都归给神。

这类献祭是祭司就职礼，不是每年节期都重复。

## 2. 每日常献燔祭

每天都要献两只一岁的公羊羔：

* 早晨一只；
* 黄昏一只。

并配上素祭和奠祭（出29:38—42；民28:3—8）。

所以民数记29章每一天列出的节期祭物，都是：

> **节期特别献祭＋每日常献燔祭。**

不是用节期献祭替代每日献祭。

---

# 四、利未记16章：赎罪日的至圣所礼仪

利未记16章不是普通节期献祭表，而是整个以色列献祭制度中最特殊的一天。

## 主要祭牲

亚伦要预备：

* 一只公牛犊，为自己和本家作赎罪祭；
* 一只公绵羊，为自己作燔祭；
* 两只公山羊，为百姓使用；
* 一只公绵羊，为百姓作燔祭。

两只公山羊拈阄：

### 第一只：归耶和华

被杀作赎罪祭，血带入幔子内，弹在施恩座前，用来洁净：

* 至圣所；
* 会幕；
* 祭坛；
* 百姓。

### 第二只：归于阿撒泻勒

大祭司把以色列人的罪承认在它头上，然后由人把它送到旷野。

这只羊不被杀在祭坛上，而是象征罪被带走。

## 利未记16章的独特之处

只有这一天：

* 大祭司可以进入至圣所；
* 必须先为自己赎罪；
* 必须带香炉，使香云遮掩施恩座；
* 要为圣所本身进行洁净；
* 有一只活着被送走的公山羊；
* 祭牲尸体要运到营外焚烧。

所以利未记16章重点不是“献多少”，而是：

> **大祭司怎样进入神面前，以及怎样洁净被百姓罪污秽的圣所。**

---

# 五、利未记23章：节期的日期和意义

利未记23章列出全年圣会：

1. 安息日；
2. 逾越节；
3. 无酵节；
4. 初熟节；
5. 七七节；
6. 吹角日；
7. 赎罪日；
8. 住棚节。

这一章重点是：

* 哪一天举行；
* 是否停止工作；
* 是否举行圣会；
* 是否刻苦己心；
* 节期纪念什么。

例如赎罪日，利未记23:26—32强调：

* 七月初十；
* 要刻苦己心；
* 不可做工；
* 是完全安息的日子。

但它没有详细展开大祭司进入至圣所的程序，也没有完整列出全部祭牲。

因此赎罪日要把三处经文合在一起：

| 经文              | 管理的层面                 |
| --------------- | --------------------- |
| **利未记16章**      | 大祭司进入至圣所的赎罪礼          |
| **利未记23:26—32** | 全民怎样守赎罪日：禁食、刻苦己心、停止工作 |
| **民数记29:7—11**  | 赎罪日额外公共燔祭和赎罪祭的数量      |

---

# 六、民数记15章：素祭和奠祭的计算标准

民数记15章主要回答一个问题：

> 献不同大小的祭牲时，应当配多少细面、油和酒？

| 祭牲    |     细面 |     油 |     酒 |
| ----- | -----: | ----: | ----: |
| 一只羊羔  | 伊法十分之一 | 欣四分之一 | 欣四分之一 |
| 一只公绵羊 | 伊法十分之二 | 欣三分之一 | 欣三分之一 |
| 一只公牛  | 伊法十分之三 | 欣二分之一 | 欣二分之一 |

所以民数记29章说“照例照数”，主要就是指民数记15章所规定的比例。

民数记15章还区分：

* 误犯的罪，可以献祭赎罪；
* 故意“擅敢行事”、公开藐视神的人，不能把献祭当成逃避审判的手段（民15:27—31）。

这说明旧约献祭并不是“犯什么罪，杀一只羊就没事”。

---

# 七、民数记28章和29章的差异

这两章是一套完整的公共献祭日历。

## 民数记28章

包括：

* 每日常献祭；
* 每周安息日祭；
* 每月月朔祭；
* 逾越节与无酵节；
* 七七节、初熟节。

可以理解为：

> 日、周、月，以及上半年节期的献祭安排。

## 民数记29章

包括：

* 七月初一吹角日；
* 七月初十赎罪日；
* 七月十五日至二十一日住棚节；
* 七月二十二日严肃会。

可以理解为：

> 七月秋季节期的献祭安排。

两章重点都是国家或全会众的公共献祭，不是个人因犯罪、还愿或感恩所献的祭。

---

# 八、其他特殊献祭章节

## 民数记5章：特殊罪责与疑恨素祭

包括：

* 亏负别人后的赔偿；
* 另加五分之一；
* 丈夫怀疑妻子不忠时的疑恨素祭。

这是特殊案件的处理，不是日常节期祭。

---

## 民数记6章：拿细耳人还愿献祭

拿细耳人完成许愿期限后，要献：

* 一只公羊羔作燔祭；
* 一只母羊羔作赎罪祭；
* 一只公绵羊作平安祭；
* 一筐无酵饼；
* 素祭和奠祭。

并在会幕门口剃头，把头发放在平安祭下的火上烧掉（民6:13—21）。

这是个人许愿结束时的献祭。

---

## 民数记7章：会幕奉献礼

十二支派首领连续十二天献礼，每个支派所献相同，包括：

* 银盘、银碗、金盂；
* 素祭用细面和油；
* 公牛、公绵羊、羊羔；
* 公山羊；
* 平安祭牲。

这是会幕和祭坛启用时的一次性奉献记录，不是每年都要照做。

---

## 民数记8章：利未人洁净礼

利未人被分别出来服侍时，要献两只公牛：

* 一只作燔祭；
* 一只作赎罪祭。

这与出埃及记29章祭司承接圣职相似，但对象不同：

* 出埃及记29章：亚伦家祭司；
* 民数记8章：一般利未人。

---

## 民数记9章、申命记16章：逾越节

逾越节羊羔与一般献祭不同：

* 为纪念神拯救以色列长子；
* 羊羔必须吃掉；
* 不可折断骨头；
* 要与无酵饼、苦菜同吃；
* 后来规定要在神所选择的地方宰杀。

民数记9章还规定，因接触死尸或远行而不能守节的人，可以在二月十四日守“第二逾越节”。

---

## 民数记19章：红母牛

红母牛礼仪很特殊：

* 必须是没有残疾、未曾负轭的红母牛；
* 带到营外宰杀；
* 整只焚烧；
* 灰保存起来，与活水混合；
* 用于洁净接触死尸的人。

它不是普通坛上的燔祭，主要解决“死亡带来的礼仪不洁”。

这与利未记16章也有相似之处：都涉及营外处理和洁净，但目的不同。

| 红母牛，民数记19章 | 赎罪日，利未记16章      |
| ---------- | --------------- |
| 洁净接触死尸的人   | 洁净圣所、祭司和全体百姓    |
| 灰可以长期保存使用  | 每年七月初十举行一次      |
| 母牛在营外焚烧    | 公牛、公山羊的尸体运到营外焚烧 |
| 一般洁净礼      | 大祭司进入至圣所的最高礼仪   |

---

# 九、利未记16章与民数记29章到底怎样同时执行

赎罪日当天至少有四层规定：

## 第一层：每日常献燔祭

按照民数记28:3—8：

* 早晨一只公羊羔；
* 黄昏一只公羊羔；
* 配素祭和奠祭。

## 第二层：赎罪日额外公共献祭

按照民数记29:7—11：

* 公牛犊一只；
* 公绵羊一只；
* 一岁公羊羔七只；
* 公山羊一只作赎罪祭；
* 配相应素祭和奠祭。

## 第三层：至圣所赎罪礼

按照利未记16章：

* 亚伦自己的赎罪公牛；
* 两只为百姓预备的公山羊；
* 亚伦自己的燔祭公绵羊；
* 百姓的燔祭公绵羊；
* 血进入至圣所；
* 活羊被送到旷野。

## 第四层：全民守节要求

按照利未记23:26—32：

* 刻苦己心；
* 不做任何工；
* 举行圣会；
* 从九日晚到十日晚守安息。

因此不是在利未记16章和民数记29章之间选择一章，而是：

> **利未记16章负责赎罪日的核心圣所礼仪；民数记29章负责当日额外的公共献祭；利未记23章负责全民守节方式；民数记28章的每日常献祭仍然继续。**

# 十、用一句话记住各章差异

| 章节               | 一句话记忆               |
| ---------------- | ------------------- |
| **利未记1—7章**      | 献祭有哪几种、每一种怎样献       |
| **出埃及记29章**      | 祭司怎样就职，每天早晚怎样献      |
| **利未记16章**       | 大祭司怎样在赎罪日进入至圣所      |
| **利未记23章**       | 全年节期是哪一天、百姓怎样守      |
| **民数记15章**       | 每种祭牲配多少细面、油和酒       |
| **民数记28—29章**    | 每日、每周、每月、每个节期献多少    |
| **利未记17、21—22章** | 在哪里献、谁能献、祭牲必须符合什么条件 |
| **申命记12、16章**    | 献祭必须集中在神所选择的地方      |

最适合的阅读顺序是：

> **利未记1—7章 → 出埃及记29章 → 利未记16章 → 利未记23章 → 民数记15章 → 民数记28—29章 → 申命记12、16章。**

这样就能从“祭的种类”，一路读到“节期时间、数量和地点”，形成完整体系。
