MagicJ 挂号真实号源助手

安装方法：
1. 解压整个文件夹。
2. 在 Chrome 地址栏打开 chrome://extensions。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本文件夹。
5. 返回 https://www.magicj.cn/officialwebsite/tools/appointment/，页面会显示“扩展已连接”。

使用说明：
- 点击网页上的“同步当前科室”，在上海申康官方网页端完成登录。
- 扩展只保存医生姓名、职称、官方简介、排班日期、上午/下午、号源状态和同步时间。
- 可按医院、科室、专家、希望就诊日期范围、上午/下午和提前分钟设置放号提醒。
- 提醒保存在本机 Chrome 中；关闭网页后，扩展仍会通过 Windows 桌面通知。
- 网页右上角的时钟可查看本机提醒记录，也可以先发送一条测试通知。
- 扩展不读取、不保存手机号、验证码、身份证号、就诊人或订单信息。
- 实际可预约状态以官方平台提交预约时的结果为准。

从 1.0.0 更新：
1. 下载并解压新版压缩包，覆盖原扩展文件夹。
2. 打开 chrome://extensions。
3. 在“MagicJ 挂号真实号源助手”卡片上点击“重新加载”。
4. 返回挂号页强制刷新，顶部应显示 v1.1.0。
